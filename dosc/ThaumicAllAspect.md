# Thaumic All Aspect

神秘时代 4（Thaumcraft 4）附属模组，适用于 Minecraft 1.7.10。自动为没有要素的物品、方块、流体和实体补充要素，已有要素从不覆盖。

---

## 基本信息

| 项目 | 说明 |
|------|------|
| Mod ID | `thaumicallaspect` |
| 依赖 | Thaumcraft 4、Baubles |
| 适用 | MC 1.7.10，Forge 10.13.4.1614+，TC 4.2.3.5+ |
| 作者 | SunMilktea |

---

## 功能概览

- **物品 / 方块 / 流体**：对没有要素的物体自动补充要素。  
  - 优先从**合成表**的原料汇总要素；  
  - 无合成表时按**类型继承**分配；  
  - 要素数量按**衰减系数**缩放（默认 0.1，即每层保留 10%，每种要素至少 1 点，可在配置中调整）。  
- **生物**：对没有要素的实体补充要素。  
  - 依据继承关系、种类、掉落物；  
  - 怪物不加野兽（BEAST），普通生物固定加 4 点野兽；  
  - 继承链上的要素同样按衰减系数缩放（至少 1 点）。  
- **不覆盖已有注册**：仅对“当前没有要素”的目标补充，Thaumcraft 及其他模组已注册的要素一律保留。

## 配置说明（ThaumicAllAspect.cfg）

- **`performance` 分类**  
  - `scanLogLevel`：扫描日志级别。  
    - `0`：完整日志（默认，便于排查问题）；  
    - `1`：只输出摘要；  
    - `2`：关闭扫描日志（加载最快）。  
  - `skipDiagnosticDumps`：跳过 AbyssalCraft 的诊断转储，减少加载时间。

- **`balance` 分类**  
  - `recipeDecay`：**全局衰减系数**（默认 `0.1`，范围 `0.05`～`1.0`）。  
    - 表示每层推导保留多少要素值，例如：  
      - `0.1`：衰减 90%，只保留 10%（链条长时数值不会爆炸）；  
      - `0.5`：衰减 50%；  
      - `1.0`：不衰减。  
    - 不论系数多少，每种要素至少保留 1 点。  
  - `enrichSingleAspect`：是否对“只有 1 种要素”的物品做**种类补充**（默认 `true`）。  
    - 打开时：顶层推导结果只有 1 种要素时，会额外用关键词兜底结果补几种新的要素进来（不覆盖原有种类），避免出现“只有一种要素”的极端情况；  
    - 关闭时：严格按照推导链结果，不做额外补充。

**推荐档位**

| 用途       | recipeDecay | enrichSingleAspect | scanLogLevel |
|------------|-------------|--------------------|--------------|
| 要素更饱满 | 0.25～0.5   | true               | 0 或 1       |
| 默认平衡   | 0.1         | true               | 0            |
| 数值更克制 | 0.05～0.1   | false              | 1 或 2       |
| 加载更快   | 0.1         | true               | 2            |

## 服务器与模组配方要素（植物魔法等）

部分模组（如植物魔法 Botania）的配方扫描在**仅服务端**环境下会因依赖客户端类而失败，导致服务器上这些模组物品没有要素。

**做法：用客户端生成的要素缓存文件给服务器用。**

1. **客户端先完整跑一遍**  
   在装有植物魔法等模组的客户端中进世界或触发一次完整扫描。扫描结束后会生成：
   - `config/ThaumicAllAspect-aspect-cache.cfg`

2. **复制到服务器**  
   将上述文件复制到服务器的 **`config/`** 目录。

3. **再启动服务器**  
   服务器启动时若发现存在 `config/ThaumicAllAspect-aspect-cache.cfg`，会先从该文件加载要素并注册到 Thaumcraft，再执行本机扫描。这样服务器无需反射 Botania 等模组，也能拥有植物魔法等内容模组的要素。

**流程小结**：客户端生成配置 → 把 `ThaumicAllAspect-aspect-cache.cfg` 拷到服务器 config → 启动服务器即可。

每次完整扫描结束后，模组会**覆盖**写出 `logs/ThaumicAllAspect-cache.cfg` 和 `config/ThaumicAllAspect-aspect-cache.cfg`（同一份完整要素缓存），不会追加。服务器端不执行模组配方反射扫描，仅从 config 缓存加载 + 本机非模组推导。

## 其他说明

- **原版与模组一视同仁**：不按 mod 跳过，`minecraft` 及所有模组物品都会参与扫描；唯一跳过条件是“该物品在 Thaumcraft 中已注册且要素非空”。
- **石英 / 岩石 / 刀剑**：对原版石英块、石英变种（楼梯/台阶/雕纹等）及岩石类（含中文名）有关键词与类型兜底；拔刀剑等刀剑类在“尚无要素”时由关键词兜底补上武器要素，已有要素的不会被覆盖。
- **矿物辞典优先**：推导顺序中会先尝试矿物辞典等价物，再配方、熔炉、类型与关键词兜底；石英等若在矿辞中有 donor 会从矿辞继承，否则走兜底。
