# Thaumic All Aspect

神秘时代 4（Thaumcraft 4）附属模组，适用于 Minecraft 1.7.10。

## 功能

- **物品 / 方块 / 流体**：自动为没有要素的物体补充要素。  
  - 优先从**合成表**的原料汇总要素；  
  - 若无合成表，则按**方块/物品类型（继承关系）**分配要素；  
  - 要素数量**衰减 50%**（至少保留 1）。  
- **生物**：自动为没有要素的实体补充要素。  
  - 依据**继承关系、种类、掉落物**分配；  
  - **怪物**不加野兽（BEAST）要素；  
  - **生物**（非怪物）固定加 **4 点野兽**要素；  
  - 要素数量**衰减 50%**。  
- **已有要素的不修改**：仅对“当前没有要素”的目标进行补充，不覆盖已有注册。

## 依赖

- Minecraft 1.7.10  
- Forge 10.13.4.1614+  
- Thaumcraft 4.2.3.5+

## 构建

```bash
./gradlew build
```

产出在 `build/libs/`。
